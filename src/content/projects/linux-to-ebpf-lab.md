## Overview

A hands-on learning journey from Linux fundamentals to kernel-level tracing with eBPF. The goal is practical understanding through experiments, scripts and debugging rather than theory alone.

## Roadmap

- **Linux fundamentals:** filesystem, permissions, users, processes and services.
- **Shell and administration:** Bash, scripting, SSH, cron and user management.
- **OS concepts:** processes and threads, system calls, scheduling, memory and file descriptors, explored with tools such as `strace`, `lsof` and `vmstat`.
- **Further topics:** networking, containers with Docker, observability and eBPF tracing.

## Why

Security and observability work depends on knowing what the system is really doing underneath, and eBPF gives a safe way to see it.
